# Jay — Portfolio

HTML + CSS + JavaScript만 사용하는 정적 포트폴리오입니다. 설치나 빌드가 필요 없습니다.

## 로컬 확인
index.html을 더블클릭해 브라우저에서 엽니다. 기본 언어 페이지로 이동합니다. 수정 후 새로고침하면 반영됩니다. Google Fonts는 인터넷 연결이 필요하며 오프라인에서는 기본 폰트를 사용합니다.

## 수정 위치
- ko/index.html, en/index.html: 언어별 소개, About, 링크, 프로젝트 카드의 제목과 설명
- projects.js: 영어 상세 창 내용과 한국어 ko 객체. 카드 data-project와 동일한 id를 사용합니다.
- style.css: 색상, 배치, 모바일 화면, 애니메이션
- script.js: 필터, 상세 창, 모션 토글

카드와 상세 창의 문구는 각각 언어별 HTML과 projects.js에서 수정합니다. 현재 프로젝트 4개는 실제 경력이 아닌 데모입니다.

## 언어 설정
site-config.js의 defaultLanguage를 'ko' 또는 'en'으로 지정합니다. 루트 방문 시 저장된 사용자 선택 → 기본 언어 순서로 이동합니다. detectBrowserLanguage를 true로 변경하면 저장된 선택 → 브라우저 언어 → 기본 언어 순서입니다. 브라우저 언어가 한국어가 아니면 영어를 선택합니다.

/ko/와 /en/은 해당 언어를 직접 표시합니다. 상단 KR / EN 링크는 현재 섹션을 유지하며 전환합니다. 파일을 직접 여는 경우에도 동작하도록 상대 경로를 사용합니다. 저장소 접근이 차단된 환경에서는 언어·모션 설정 저장 없이 작동합니다.

## 배경과 모션
다크 테마가 기본입니다. dots.js는 마우스 주변 도트가 밀려났다가 복귀하는 효과를 그립니다. 터치 기기에서는 정적인 배경입니다. 모션을 끄면 도트 반응, 장식 회전, 호버 확대와 부드러운 스크롤을 중지하고 선택을 저장합니다. OS의 동작 줄이기가 활성화된 경우 모션을 강제로 끄고 토글을 비활성화합니다. 필터와 상세 창 기능은 유지됩니다.
